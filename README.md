📊 Manipulação de Listas em Python

Este projeto foi desenvolvido com o objetivo de praticar conceitos fundamentais de programação em Python, com foco em estruturas de dados do tipo lista.

O sistema permite a entrada dinâmica de números inteiros pelo usuário, armazenando-os em uma lista até que seja informado um valor de parada. Ao final da execução, o programa realiza o processamento dos dados e apresenta:

- Quantidade total de elementos inseridos
- Maior valor da lista
- Menor valor da lista

Além disso, o programa trata o cenário em que nenhuma entrada válida é fornecida, garantindo uma resposta adequada ao usuário.

🚀 Tecnologias utilizadas
- Python

🎯 Objetivo
Praticar lógica de programação, manipulação de listas e uso de funções nativas da linguagem, como `max()`, `min()` e `len()`.
